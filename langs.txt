Thoughts on 'secret' type.  We want to extend the type system to add a
'secret' predicate.  Any time data is fetched from a `(secret ...)` datum,
it contaminates all data derived from it, and we ensure that no secret is
ever used as a branching condition.  Since `if` is our only way to branch,
this should be relatively simple, no?

It's important that we don't accidentally introduce a %prim that branches
on secret data.

ref, set! etc...

I think it should be possible to automatically do the ML 'ref' thing,
by just making a note whenever a variable is set! and automagically
turning it into a ref.  Then, vars that are not set can remain cps
`letval`, and we can get rid of the cps:let vs cps:letvar distinction.
